# Pacman Game

A simple Pacman clone built with Python and Pygame.

## Installation

1.  Make sure you have Python 3 installed.
2.  Install the required dependencies:

    ```bash
    pip install -r requirements.txt
    ```

## How to Play

1.  Run the game:

    ```bash
    python3 pacman_game/main.py
    ```

2.  Controls:
    *   **Arrow Keys:** Move Pacman (Up, Down, Left, Right).
    *   **Space Bar:** Start game / Restart after Game Over or Win.

3.  Objective:
    *   Eat all the dots to win.
    *   Avoid the ghosts! If they touch you, it's Game Over.

## Features

*   Classic maze layout.
*   Score tracking.
*   Win and Loss conditions.
*   Basic ghost AI.
